# Machine Learning Practicals – Spring 2026

This repository contains **Machine Learning practical codes** maintained as part of the **Machine Learning course (Spring 2026)** at **Sitare University**.  
Each folder corresponds to one practical session conducted during tutorials and lab hours.

---

## 🎯 Course Objectives
- Learn how machines improve from data using practical algorithms
- Understand prediction, representation, and decision-making models
- Gain hands-on experience with supervised and unsupervised learning techniques

---

## 📚 Syllabus Coverage
The practicals in this repository are aligned with the official course syllabus, including:

- Introduction to Machine Learning
- Supervised Learning  
  - Linear Regression  
  - Logistic Regression  
- Model Evaluation Metrics
- Neural Networks
- Neural Network Training and Optimization
- Decision Trees
- Unsupervised Learning  
  - K-Means Clustering  
  - Anomaly Detection
- Recommender Systems
- Reinforcement Learning
